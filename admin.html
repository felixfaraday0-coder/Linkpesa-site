Administrator setup guide

Private admin area is not implemented. This public starter page is a checklist, not a secure admin dashboard. Do not publish private customer or payout data here.

Daily administration

  1. Review new registrations in the restricted Google Sheet.
  2. Assign a unique member ID and referral code.
  3. Record advertiser, offer, tracking link and written commission terms.
  4. Import or review advertiser conversion reports.
  5. Mark conversions pending until validated.
  6. Approve only commissions confirmed and payable under the advertiser agreement.
  7. Record M-Pesa payout date, amount and transaction reference; mask sensitive details.

Access control

  • Keep the member and payout spreadsheet restricted to the administrator.
  • Do not publish a Google Sheet containing phone numbers or balances.
  • Use a separate business Google account and strong two-step verification.
  • Before automating logins or payouts, use a proper backend with secure authentication and audit logs.

M-Pesa

Start by recording manual payouts made through your normal M-Pesa business process. Daraja API automation requires Safaricom developer registration, approved credentials, testing and secure server-side integration. Never put API secrets in website code.
